# AGENTS.md

Engineering handbook and default GitHub community files. Read `standards/*.md`
before editing. Scope for this showcase is D:/showcase only.

## Commands

- Validate: parse YAML, check Markdown links and inspect `git diff --check`.
- Every change goes through a Conventional Commit PR; never push directly to main.
- Actions use full commit SHAs; shared platform workflows use `@v1`.

## Glossary

| Name | Meaning |
|---|---|
| handbook | written engineering standards in `standards/` |
| baseline | shared files distributed by pull request |
| governance | repository settings, audit reports and recurring conformance |

## Change policy

Describe planned automation as planned until it has been deployed and verified.
Keep the handbook aligned with enforcement. Never expose credentials.
