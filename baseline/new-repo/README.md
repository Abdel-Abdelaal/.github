## Contributing

The starter includes shared policy/security checks, advisory PR review, weekly AI
audits and fix proposals, baseline updates, stale-item maintenance and Scorecard.
Configure AI_API_KEY for inference. Fix/baseline PR creation also needs the
automation App; missing credentials skip explicitly. Add language-specific checks
and dependency update entries for this repository's actual implementation.
For a default branch other than main, adjust branch event filters and use a platform
release that supports the repository's default branch for scheduled AI.

Signed public records appear on the
[fleet AI dashboard](https://abdel-abdelaal.github.io/github-governance/), whose
collector discovers new public repositories each run. A repository with no records
is awaiting evidence. Private prompts, outputs and repository identities must stay
private; do not activate public attestation/publishing for a private repository.
Private telemetry needs its separate private signing/storage path.

Changes go through pull requests with Conventional Commit titles. See the
[handbook](https://github.com/Abdel-Abdelaal/.github/tree/main/standards) and
[CONTRIBUTING](https://github.com/Abdel-Abdelaal/.github/blob/main/CONTRIBUTING.md).
